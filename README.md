# P.I.P.O — Programme Interactif pour Pompier Organisé

Application de révision en QCM des guides nationaux de doctrine (GDO) et de techniques opérationnelles (GTO) publiés par la DGSCGC, du niveau équipier au niveau chef d'agrès.

- Questions rédigées puis vérifiées d'après les PDF officiels (site de la Sécurité civile, versions en ligne en juillet 2026) ; chaque correction cite le passage du guide, avec sa section et sa page.
- Révision espacée, examen blanc chronométré, points faibles, recherche, flashcards.
- La progression est enregistrée dans le navigateur de chaque utilisateur (aucune donnée envoyée).

Support de révision non officiel : les consignes de votre SDIS priment toujours.

Le site est un simple fichier `index.html`, publié avec GitHub Pages.
